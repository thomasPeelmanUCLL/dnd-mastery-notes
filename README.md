# D&D 5e (2024 Rules) Notes

This repository contains reference material and character documentation for D&D 5e using the 2024 Player's Handbook rules.

## Contents

- **[Character Sheet – Paladin 3 (Oath of Glory)](character-sheet-paladin-3.md)**  
  Full character sheet for a Level 3 Dwarf Paladin (Noble background, Oath of Glory), including:
  - Ability scores, combat stats, and saving throws
  - Species traits (Dwarf), background features (Noble), and class features (Paladin)
  - Oath of Glory tenets, spells, and Channel Divinity options
  - Skill list, weapon attacks (longsword, javelin), languages, equipment
  - Prepared spells, action economy, and quick reference

- **[Weapon Mastery Notes](mastery-notes.md)**  
  Concise reference for weapon mastery properties in the 2024 rules, currently covering:
  - Longsword – **Sap** (impose disadvantage on the target's next attack)
  - Javelin – **Slow** (reduce target's speed by 10 feet)
  - How Weapon Mastery works and how martial classes unlock these properties
  - A checklist of missing parts to expand (other mastery properties, examples, FAQs)

## Usage

- Use `character-sheet-paladin-3.md` as a template or reference when building or playing a similar Paladin.
- Use `mastery-notes.md` to quickly look up how mastery properties work and what longsword/javelin do.
- Both files are plain Markdown, so you can read them on GitHub or download and open them in any Markdown editor.
